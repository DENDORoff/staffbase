Пояснительная записка и вспомогательные материалы к проекту StaffBase.
Курсовая работа по дисциплине «Разработка программного обеспечения», ВКЭиК, группа ПО-314,
студент Колот Д. Д., руководитель Соколова Е. В., Павлодар, 2026.

## Состав

| Каталог | Что лежит |
|---|---|
| `документы/` | `Колот_ДД_ПО-314_Курсовая_StaffBase.docx` — пояснительная записка (55 стр.) и её PDF-версия для печати/просмотра |
| `screenshots/` | 15 изображений: 12 скриншотов интерфейса (вход, обзор, сотрудники, карточка, отпуска, отделы, настройки, публичная главная, должности, импорт CSV, пользователи, тёмная тема) и 3 изображения схем (ER-модель, компоненты, алгоритм заявки) |
| `diagrams/` | Исходники схем в формате HTML (`diagram-er.html`, `diagram-arch.html`, `diagram-flow.html`) и их экспорт в JPEG — те же три схемы, что вставлены в записку |
| `tools/` | Скрипты генерации и проверки записки (см. ниже), а также результаты замеров Lighthouse |

Файлы `_pdfcheck/` и `node_modules/` в репозиторий не включены: это временные артефакты проверки и установленные зависимости.

## Зачем нужны скрипты в `tools/`

Это не часть веб-приложения, а «фабрика» документа:

| Файл | Назначение |
|---|---|
| `make-docx.mjs` | Собирает DOCX из текста, таблиц, рисунков и листингов, задаёт оформление по методичке (А4, Times New Roman 14 pt, поля 2,5 / 2 / 2 / 2,5 см, одинарный интервал, отступ абзаца 1,25 см), нумерацию и колонтитулы. Результат — `документы/*.docx` |
| `jpeg-size.mjs` | Читает размеры JPEG, чтобы вставлять рисунки в Word с правильными пропорциями |
| `pdf-pages.mjs` | Постраничный дамп текста из PDF (pdfjs-dist): показывает структуру записки и число страниц после правок |
| `qa-delete.mjs` | Разовая проверка формы удаления персональных данных: показывает запросы в таблице `data_deletion_requests` и удаляет тестовую запись `qa-delete@staffbase.kz` из демонстрационной базы |
| `lh-mobile.json`, `lh-desktop.json` | Реальные результаты Lighthouse 13 от 19.11.2026, из которых взяты числа в таблице 3.3 записки (моб. 97 / SEO 100 / доступность 100; десктоп 99 / 100 / 100) |

## Как пересобрать записку

```powershell
cd coursework\tools
npm install
node make-docx.mjs
```

Скрипт перезапишет `coursework\документы\Колот_ДД_ПО-314_Курсовая_StaffBase.docx`.
Данные берутся из соседних каталогов (`screenshots/`, `diagrams/`), так что скрипт переносим.
После генерации откройте DOCX в Word и обновите поле содержания: **Ctrl+A → F9** — номера страниц в оглавлении подтянутся автоматически.

Для проверки числа страниц:

```powershell
# из корня репозитория
& "C:\Program Files\LibreOffice\program\soffice.exe" --headless --convert-to pdf --outdir coursework\_pdfcheck coursework\документы\Колот_ДД_ПО-314_Курсовая_StaffBase.docx
node coursework\tools\pdf-pages.mjs "coursework\_pdfcheck\Колот_ДД_ПО-314_Курсовая_StaffBase.pdf"
```

## Структура записки

- Титульный лист, задание, содержание, введение;
- Раздел 1 — анализ предметной области: пользователи, объекты учёта, функциональные и нефункциональные требования, правила обработки данных, законодательство РК, аналоги, бизнес-процессы, этапы работ;
- Раздел 2 — проектирование: выбор стека и сравнение с аналогами (таблица 2.9), схема базы данных, структура приложения и алгоритмы, поля таблиц, интерфейс, модель угроз, SEO и доступность;
- Раздел 3 — реализация и проверка: функции с листингами, экраны, состояния интерфейса, эксплуатация, адаптивность, производительность, юридический чек-лист, 18 функциональных тестов;
- Заключение, список использованных источников (17), приложения А (SQL-скрипт), Б (формат CSV), В (учётные записи и репозиторий), Д (инструкция по запуску).

Собственно приложение находится в корне репозитория; запуск и демо-доступ описаны в [главном README](../README.md).
