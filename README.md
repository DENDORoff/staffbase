# StaffBase — система учёта сотрудников компании

Внутренняя кадровая система ТОО «DeWorld StaffBase» (г. Павлодар): карточки 40 сотрудников, справочники отделов и должностей, заявки на отпуска и больничные с согласованием, дашборд для руководства, поиск и выгрузка данных в CSV, ролевая модель доступа.

Курсовая работа по дисциплине «Разработка программного обеспечения», ВКЭиК, группа ПО-314, студент Колот Д. Д., руководитель Соколова Е. В., Павлодар, 2026.

**Репозиторий:** https://github.com/DENDORoff/staffbase
**Демо:** https://staffbase.de-world.net · запасной: https://staffbase-qrnwngeis-dw-8bb0.vercel.app
**Развернуть локально за 5 минут:** `npm install` → `cp .env.example .env.local` → `node scripts/seed.mjs` → `npm run build` → `npm start` → http://localhost:3000

## Что внутри

| Слой | Решение | Почему так |
|---|---|---|
| UI + сервер | Next.js 16 (App Router), React 19, TypeScript | SSR — страницы отдаются готовыми; единый код клиента и сервера |
| Стили | Tailwind CSS 4, PT Sans / PT Serif self-hosted | корпоративная палитра, шрифты с нашего сервера, без CDN |
| БД | PostgreSQL 17 на Neon (eu-central-1), `@neondatabase/serverless` | серверная СУБД для 40 пользователей; serverless-тариф; пул соединений |
| Доступ к данным | прямые параметризованные SQL (без ORM) | полный контроль запросов; нет склейки строк SQL; ограничения целостности в самой БД |
| Аутентификация | собственная: scrypt + индивидуальная соль, сессии в БД (SHA-256 токена), httpOnly cookie, CSRF-токен | пароль в БД невосстановим; блокировка после 5 ошибок на 15 минут |
| Обмен данными | CSV с разделителем «;» и BOM, RFC 4180 | мгновенно открывается в Excel; импорт с отчётом о строках-ошибках |
| Локализация | RU / EN / KZ, переключение в настройках | интерфейс компании на трёх рабочих языках |
| Темы | системная / светлая / тёмная | доступность и работа в разных условиях |
| Проверки | сквозные: валидация на сервере, FK RESTRICT, CHECK, UNIQUE, CSRF | ошибки не зависят от честности клиента |

## Требования

- Node.js 20+ (разработка — на v26)
- Доступ к Neon-проекту `staffbase` (или собственная строка подключения PostgreSQL 17)
- Опционально: Docker (для запуска без Node.js на хосте)

## Быстрый старт (локально)

```powershell
git clone https://github.com/DENDORoff/staffbase.git
cd staffbase
Copy-Item .env.example .env.local   # вставить DATABASE_URL и SESSION_SECRET
npm install
node scripts/seed.mjs               # пересоздаёт схему и заливает учебные данные
npm run dev                         # http://localhost:3000
```

> В PowerShell `npm` может быть заблокирован политикой — используйте `npm.cmd`.

Production-режим локально:

```powershell
npm run build
npm start
```

### Через Docker

```powershell
Copy-Item .env.example .env.local   # вставить DATABASE_URL и SESSION_SECRET
docker compose up --build            # http://localhost:3000
```

Образ multi-stage (node:22-alpine, non-root user), БД — внешний Neon, поэтому compose прост: один сервис, переменные из `.env.local`.

## Сценарий демонстрации (6–7 минут)

1. Войти под `hr@staffbase.kz` → «Обзор»: живые показатели (38 работают / 1 в отпуске / 1 на больничном), распределение по отделам, заявки на рассмотрении.
2. «Сотрудники» → поиск «Колот» → карточка TB-0001 → редактирование телефона → сохранение.
3. Фильтр «Отдел = ИТ», сортировка по дате приёма, слайдер «Оклад не выше».
4. «Отпуска и больничные» → открыть заявку Абдрахманова (14.12–28.12) → «Согласовать».
5. «Сотрудники» → «CSV» — скачать файл, открыть в Excel (кириллица читается).
6. «Импорт» → загрузить выгруженный файл обратно — нулевые ошибки; загрузить файл с испорченной строкой — отчёт с номерами строк.
7. «Настройки» → тема «Тёмная» → язык «KZ» → обратно «RU / Системная».
8. Выйти → войти под `employee@staffbase.kz` → убедиться, что столбец «Оклад» и раздел «Пользователи» недоступны.

## Что реализовано (проверено)

- Вход с блокировкой после 5 ошибок на 15 минут; сессия 8 часов; пароли scrypt.
- Ролевая модель: администратор / руководитель / сотрудник; админ-раздел управления учётными записями (создание, смена роли, защита последнего администратора).
- Справочники отделов и должностей с контролем ссылочной целостности (FK RESTRICT).
- Карточки сотрудников: табельный номер TB-NNNN, связи с отделом и должностью, возрастные и окладные ограничения на сервере.
- Поиск, фильтры (отдел / должность / статус / оклад-слайдер), сортировка по ФИО, дате приёма, окладу; пагинация по 10.
- Дашборд: численность, распределение по отделам, фонд оплаты, заявки на рассмотрении, недавние приёмы.
- Отпуска и больничные: вкладки (все / на рассмотрении / согласованные), согласование и отклонение; период, включающий сегодня, меняет статус сотрудника автоматически.
- CSV: экспорт с BOM и разделителем `;`, даты ГГГГ-ММ-ДД; импорт upsert по табельному номеру, строки с ошибками не сохраняются и перечисляются.
- Экспортируемые и импортируемые даты в формате `ГГГГ-ММ-ДД`; экранирование по RFC 4180.
- Юридические страницы: конфиденциальность, условия, cookie, согласие на обработку ПД, возврат средств, запрос на удаление данных, реквизиты; cookie-баннер; возрастное подтверждение.
- SEO и производительность: SSR, `sitemap.xml`, `robots.txt`, `manifest.webmanifest`, OpenGraph-картинка, self-hosted шрифты, skip-link, focus-visible, prefers-reduced-motion.
- Безопасность: CSP, `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy`, `Permissions-Policy`; CSRF на каждой форме; параметризованные SQL; `.env*` в .gitignore.

## Ограничения (честно)

- Email-уведомления о новых заявках не отправляются: в профиле сохраняется только флаг «получать уведомления».
- Статус сотрудника при окончании согласованного отпуска не возвращается к «Работает» автоматически (меняется только при согласовании, включающем сегодня).
- Импорт CSV обновляет записи по табельному номеру; дубликаты по почте отклоняются с сообщением.
- Офлайн-режим и PWA не реализованы; приложение рассчитано на сеть.
- Реквизиты компании на страницах /legal являются учебными (помечены в футере и на странице «Реквизиты»).
- Экономическая часть и расчёт зарплаты не входят в курс работы.

## Vercel (production)

Проект привязан к GitHub → Vercel (auto-deploy из `main`). Переменные окружения в проекте Vercel: `DATABASE_URL` (Neon, pooler), `SESSION_SECRET`. Домен `staffbase.de-world.net` подключается в настройках проекта (DNS-запись CNAME → `cname.vercel-dns.com` на DNS-хостере домена).
